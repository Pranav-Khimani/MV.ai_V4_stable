MV.AI CLEAN SCREENSHOT PATCH

This patch:
- removes the old PIL-based tools/screenshot_tool.py file
- removes stale screenshot .pyc cache files
- keeps the working screenshot tool in tools/system/
- changes the chat reply to: Screenshot captured.
- shows a Windows tray notification after every screenshot
- does not open or preview the screenshot

HOW TO APPLY
1. Copy PATCH_FILES and APPLY_CLEAN_SCREENSHOT_PATCH.bat into MV.ai_V4.
2. Fully close MV.AI.
3. Double-click APPLY_CLEAN_SCREENSHOT_PATCH.bat.
4. Restart MV.AI.
5. Test: take a screenshot
